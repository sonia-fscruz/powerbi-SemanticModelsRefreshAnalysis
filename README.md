# powerbi-SemanticModelsRefreshAnalysis
Power BI based solution for analyzing Semantic Model refreshes

How to use it:

Open the Power BI Template file (.pbit), and you will be promted to enter your TenantId, ClientId and ClientSecret.
After this the model will refresh with your data and you'll be able to see the report.
